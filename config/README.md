# Configuration Directory

This directory stores the application's configuration file.

## Files

- `.env.php` - Auto-generated by installer (DO NOT commit to Git)

## Security

This directory must be:
- **Writable** by the web server (chmod 770)
- **Protected** from web access (handled by .htaccess)
- **Never committed** to version control (.gitignore)

## Contents After Installation

```php
config/.env.php  // Application configuration
```

The installer wizard creates `.env.php` with your:
- Database credentials
- SAML settings
- Security configuration
- Session settings
- Upload limits
