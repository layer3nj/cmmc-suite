1. Overview

The CMMC Compliance Suite is a self-contained PHP application for tracking compliance with:

  • CMMC 2.0 - Maturity Levels 1-3
  • NIST SP 800-171 - All 110 security practices
  • DISA STIGs - Security Technical Implementation Guides
  • SPRS Scoring - DoD assessment methodology
  • POA&M Tracking - Plan of Action & Milestones

2. Server Requirements

Minimum Server Specifications

  • PHP: 8.1 or higher
  • Web Server: Apache 2.4+ with mod_rewrite OR nginx 1.18+
  • Database: MySQL 5.7+ / MariaDB 10.3+ OR PostgreSQL 12+
  • RAM: 512 MB minimum (1 GB recommended)
  • Disk Space: 100 MB minimum

Required PHP Extensions

  • pdo - PDO extension
  • pdo_mysql - MySQL driver (if using MySQL)
  • pdo_pgsql - PostgreSQL driver (if using PostgreSQL)
  • openssl - For encryption and SAML
  • mbstring - Multi-byte string handling
  • curl - For API integrations
  • gd - Image processing
  • zip - Archive handling
Note: The installer wizard will check all requirements automatically.

3. Quick Start (5 Minutes)

  1. Download the application package
  2. Unzip to your web server's document root
  3. Set permissions on two directories: 
    chmod 770 config/
chmod 770 storage/
  4. Create a database (MySQL or PostgreSQL)
  5. Visit http://your-domain.com/install in your browser
  6. Follow the wizard - it will guide you through setup
That's it! The browser-based installer handles everything else.

4. Detailed Setup Instructions

Step 1: Prepare Your Server

For Ubuntu/Debian:

sudo apt update
sudo apt install apache2 php8.1 php8.1-mysql php8.1-pgsql php8.1-xml \
    php8.1-curl php8.1-mbstring php8.1-gd php8.1-zip mysql-server

# Enable Apache modules
sudo a2enmod rewrite
sudo systemctl restart apache2

For CentOS/RHEL:

sudo yum install httpd php php-mysqlnd php-pdo php-xml php-mbstring \
    php-gd php-zip mariadb-server

sudo systemctl enable httpd mariadb
sudo systemctl start httpd mariadb

Step 2: Download and Extract

# Download the application
cd /var/www/html
sudo wget https://your-download-url/cmmc-suite.zip
sudo unzip cmmc-suite.zip
sudo mv cmmc-suite cmmc

# Or clone from Git
git clone https://github.com/your-org/cmmc-suite.git cmmc

Step 3: Set Permissions

cd /var/www/html/cmmc

# Set ownership (replace www-data with your web server user)
sudo chown -R www-data:www-data .

# Set directory permissions
sudo chmod 755 .
sudo chmod -R 755 public/
sudo chmod -R 755 app/
sudo chmod -R 755 database/
sudo chmod -R 755 vendor/

# Set writable directories
sudo chmod 770 config/
sudo chmod 770 storage/
sudo chmod -R 770 storage/*
Security Note: Only config/ and storage/ need write permissions. Never make the entire application writable.

Step 4: Database Creation

MySQL/MariaDB:

mysql -u root -p

CREATE DATABASE cmmc_compliance CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'cmmc_user'@'localhost' IDENTIFIED BY 'secure_password_here';
GRANT ALL PRIVILEGES ON cmmc_compliance.* TO 'cmmc_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

PostgreSQL:

sudo -u postgres psql

CREATE DATABASE cmmc_compliance;
CREATE USER cmmc_user WITH ENCRYPTED PASSWORD 'secure_password_here';
GRANT ALL PRIVILEGES ON DATABASE cmmc_compliance TO cmmc_user;
\q

Step 5: Run the Installer

Open your web browser and navigate to:

http://your-domain.com/cmmc/install

The installer will guide you through 6 steps:

5. Web Server Configuration

Apache Configuration

The included .htaccess file handles URL rewriting automatically. Just ensure mod_rewrite is enabled:

sudo a2enmod rewrite
sudo systemctl restart apache2

Virtual Host Configuration:

<VirtualHost *:80>
    ServerName cmmc.your-domain.com
    DocumentRoot /var/www/html/cmmc/public

    <Directory /var/www/html/cmmc/public>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/cmmc_error.log
    CustomLog ${APACHE_LOG_DIR}/cmmc_access.log combined
</VirtualHost>

nginx Configuration

Create /etc/nginx/sites-available/cmmc:

server {
    listen 80;
    server_name cmmc.your-domain.com;
    root /var/www/html/cmmc/public;
    index index.php;

    # Security headers
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\. {
        deny all;
    }
}

Enable the site:

sudo ln -s /etc/nginx/sites-available/cmmc /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

SSL/TLS Configuration (Recommended)

Use Let's Encrypt for free SSL certificates:

sudo apt install certbot python3-certbot-apache
sudo certbot --apache -d cmmc.your-domain.com

Or for nginx:

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d cmmc.your-domain.com

7. Microsoft Entra (Azure AD) SAML Setup

In Azure Portal:

  1. Go to Azure Active Directory → Enterprise Applications
  2. Click New Application → Create your own application
  3. Name it "CMMC Compliance Suite" and select Integrate any other application
  4. Go to Single sign-on → Select SAML
  5. Configure with these URLs (from installer):
Entity ID: https://cmmc.your-domain.com
Reply URL (ACS): https://cmmc.your-domain.com/saml/acs
Sign on URL: https://cmmc.your-domain.com/saml/login
  1. Under Attributes & Claims, ensure these are mapped:
    • user.mail → email
    • user.displayname → displayName
    • user.groups → groups (optional)
  2. Download the Federation Metadata XML or copy the App Federation Metadata URL

In the CMMC Installer:

  1. Check "Enable SAML SSO"
  2. Paste the IdP Metadata URL OR upload the XML file
  3. Optionally configure group-to-role mappings

Group-to-Role Mapping

Map Azure AD groups to application roles:

  • CMMC-Admins → admin
  • CMMC-Auditors → auditor
  • CMMC-Contributors → contributor
  • CMMC-Viewers → viewer

9. Troubleshooting

Problem: "500 Internal Server Error"

Solution:

  1. Check Apache/nginx error logs: 
    sudo tail -f /var/log/apache2/error.log
sudo tail -f /var/log/nginx/error.log
  2. Check PHP error logs: 
    sudo tail -f /var/log/php8.1-fpm.log
cat storage/logs/php_errors.log
  3. Verify file permissions on config/ and storage/

Problem: "Database connection failed"

Solution:

  1. Verify database credentials
  2. Check database is running: 
    sudo systemctl status mysql
sudo systemctl status postgresql
  3. Test connection manually: 
    mysql -u cmmc_user -p cmmc_compliance
psql -U cmmc_user -d cmmc_compliance

Problem: ".htaccess not working"

Solution:

  1. Enable mod_rewrite: sudo a2enmod rewrite
  2. Set AllowOverride All in Apache virtual host
  3. Restart Apache: sudo systemctl restart apache2

Problem: "CSRF token validation failed"

Solution:

  1. Ensure cookies are enabled in your browser
  2. Check session storage is writable: sudo chmod 770 storage/sessions
  3. Clear browser cache and cookies
