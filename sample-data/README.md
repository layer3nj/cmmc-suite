# Sample Data

This directory contains sample data exports that can be imported for demonstration purposes.

## Contents

- `demo-customer.json` - Sample customer with assessments
- `demo-poam.csv` - Sample POA&M items
- `control-checklist.xlsx` - Blank CMMC/NIST checklist template

## How to Import

1. Log into the CMMC Compliance Suite
2. Navigate to **Admin** → **Import**
3. Select the file type and upload
4. Follow the import wizard

## Creating Your Own Exports

To export data for backup or sharing:

1. Navigate to **Reports** → **Export Data**
2. Select the data types to export
3. Choose format (JSON, CSV, or Excel)
4. Download the file

## Note

Sample data is provided for demonstration purposes only. Do not use in production without review.
